# 报告视角红线与语言风格

## 定位

报告是保险公司/健康管理机构提供给**投保单位人力资源部门**的员工健康与风险减量管理增值服务。读者是 HR，不是精算师。全篇视角 = **员工健康 + 企业费用效率 + 服务承诺**。

## 禁词表（出现即返工）

### 保险方内部语汇（核保/定价/盈利视角）

| 禁用 | 替代表述 |
|---|---|
| 赔付率 | 医疗费用增速 / 费用涨幅（如"费用三年 +45.5%"） |
| 核保 / 承保 | 服务覆盖 / 保障范围 |
| 定价 / 费率 / 涨价 / 精算 | ——（不出现；费用话题只谈"企业医疗支出效率"） |
| 盈亏 / 亏损 / 承保盈亏线 | 费用可持续性 |
| 满期（保费/赔付率） | 年度（医疗费用总额） |
| 超赔 / Stop-Loss | 大额风险 / 尾部费用 |
| 免赔额 / 共付比例 / 等待期 | ——（属方案调整，服务报告中不出现） |
| 既往症约定承保 | 带病体保障（正面表述福利优势） |

### 销售经营语汇（保险公司客户经营视角）

| 禁用 | 替代表述 |
|---|---|
| 客户粘性 / 粘性运营 | 全年服务计划 / 协作机制 |
| 续保率 / 加保率 | ——（不出现；这是保险方销售指标） |
| 离不开 / 换不起 / 留得住 | 省时间 / 有温度 / 有依据 / 有声量（四层服务价值） |
| 客户经营 / 触点动作 | 服务安排 / 服务触达 |
| 风险敞口 | 费用风险 / 重点风险人群 |

### AI 味表述

| 禁用 | 说明 |
|---|---|
| "一句话："式标签 | 曾用于结论框前缀，AI 味重，已全面删除；结论框直接以实质内容开头 |
| "首先/其次/最后"式机械排比 | 用表格与图表替代 |
| "值得注意的是"“不难发现" | 直接给结论 |

## 视角转译对照（核心改写模式）

| 保险公司视角（禁止） | HR 服务视角（采用） |
|---|---|
| 赔付率仪表盘 97.7%，100% 红线＝亏损 | "医疗费用涨得比人快"：费用三年 +45.5% vs 人数仅 +14.3% |
| 情景预测：费率上调 10%，赔付率 112%→91.4% | 医疗费用总额情景：维持现状 X 万 / 基础宣教 X 万 / 综合干预 X 万（省约 X 万） |
| 续保方案优化（免赔额/共付/责任分级） | 整节不出现；服务报告只谈健康管理与费用效率 |
| 超赔个案分析 | 大额理赔个案分析 |
| 慢病管理减损对赌结算 | 服务效果评估机制 |
| 早筛抬升重疾发生率，定价需评估 | 早确诊、早手术、少受罪、少花钱，术后快速返岗 |

## 语言风格规则

1. **图表为主，文字只留结论**：每个分析维度 = 1 个交互图表（ECharts）+ 1 张数据表 + 1 个结论框（note/warn/insight 三色样式）
2. **通俗化**：专业术语配通俗解释（附录口径表加"通俗理解"列，如：出险率＝每 100 人多少人报过销）
3. **KPI 面向 HR**：建档率、管理覆盖率、体检闭环率、响应时效、员工满意度 NPS、医疗费用总额增速
4. **服务承诺口吻**：第八章（全年服务计划）写"服务团队做什么、贵司投入什么、贵司可用什么标准考核我们"，不写"我们如何经营客户"
5. **数字必须由数据计算注入**，禁止叙事中手写硬编码金额/占比；口径不确定的宁可不写
6. **脱敏红线**：个案呈现只保留性别/年龄段/诊断/金额，禁止姓名、证件号、完整出生日期；报告附隐私声明（聚合视图，个人患病信息不经授权不向雇主披露）

## 报告开头必带的口径声明模板

> 本报告基于贵司 {YYYY/YYYY/...} 保单年度团体保险理赔数据编制。因报销模式为集中提交，报告中的时间维度分析采用**报案日期口径**；{YYYY} 年度为进行中年度，趋势结论以完整年度为准。个案信息均已脱敏。
