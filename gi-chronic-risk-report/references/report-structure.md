# 报告结构与图表规范

## 命名规范

- 文件名：`{企业简称}-健康风险管理服务报告-{YYYYMM}.html`
- 报告标题：`团体保险客户健康风险管理增值服务报告`
- 副标题按数据实情：`疾病出险分布 · 慢病人群画像 · 风险分层管理 · 健康服务计划`
- 封面样本编号：`GHM-{YYYY}-{序号}`

## 技术栈与骨架

- 单文件 HTML + ECharts 5（CDN 双源回退：cdn.staticfile.net 主、jsdelivr 备）
- 报告色系：主蓝 #0f4c81、辅青 #0e8388、警示红 #c0392b、琥珀 #d68910、绿 #1e8449
- 图表初始化框架：`mk(id, option)` 封装 + resize 监听数组；图表容器 `id="chartXxx"`
- 自适应：`@media (max-width:860px)` 网格降列；`@media print` 打印样式
- 长文件分段构建：Write 首段（头+样式+封面+摘要）→ Edit 逐章替换占位符（`<!-- PARTn -->`），单次写入过长会被截断

## 分层标准与服务包（第七章核心）

| 层 | 判定（人级） | 服务包 |
|---|---|---|
| 红 | 慢病 且（累计件数≥7 或 累计给付≥2 万） | 一对一建档随访、专病管理、就医绿通、季度评估 |
| 黄 | 慢病 其余 | 群组管理、年度专病筛查提醒、健康讲座定向邀约 |
| 绿 | 非慢病 | 全员健康促进、体检异常闭环提醒、线上自助工具 |

## 投入产出测算口径

- 投入：按分层人数 × 服务单价（红 ~500 元/人/年、黄 ~150、绿 ~30，按当地服务商行情调整）
- 减损基准：慢病人群住院给付中"并发症及进展相关"部分（可干预比例 25%–35%，保守/中性/乐观三情景）
- 收益另计（不重复计算）：就诊行为优化收益（如线上报销、按月提交带来的体验改善）单独陈述，不与减损混算
- 报告中明确标注"测算存在不确定性，建议服务效果评估机制"

## 校验要点（生成后必做）

1. 图表容器 ID 与 `mk()` 调用数完全相等
2. `node --check` JS 语法通过（重点：ECharts series 对象闭合层级——label 的 `}}` 后接 `]` 还是 `}]`）
3. HTMLParser 栈式校验标签配对（注意 JS 字符串中的 div 干扰计数，须先剥离 script 块）
4. 禁词表扫描零命中（见 report-perspective.md）
5. 隐私扫描：证件号正则 `\d{6}\*+\d`、手机号 `1[3-9]\d{9}`、姓名/证件号字段名
6. 关键数字抽查：报告 HTML 中 grep 的 KPI 数字与 JSON 实算值一致（手写硬编码数字是最大翻车源）
