# gi-chronic-risk-report · 团单慢病风险减量评估报告技能

基于**团体保险理赔数据**为投保单位（企业人力资源部门）生成**员工健康风险管理增值服务报告**的完整技能：疾病出险分布、慢病人群画像、红黄绿风险分层、大额个案分析、慢病风险减量方案与全年服务计划。

适用于 WorkBuddy / Claude Code 等支持 Skills 目录规范的 AI 助手环境。

## 功能定位

输入保险公司核心系统导出的**赔案明细清单（xls）**与**团体保单赔付统计报表（xlsx）**，产出单文件交互式 HTML 报告（ECharts 图表 + 结构化表格），可直接交付企业 HR。

## 8 步工作流

```
1. 数据探查   → 文件格式、表头结构（列名别名映射）、企业归属、年度范围
2. 质量诊断   → 批次报销伪像 / 导出行数截断 / 年度缺失，确定分析口径
3. 数据画像   → 年度分布、住院/门诊、人员去重、金额分层
4. 病种归类   → 16 类目 ICD 关键词映射 + 慢病队列识别
5. 深度分析   → 慢病 vs 非慢病、红黄绿分层、大额个案、高频人群
6. 报告生成   → 分析脚本出 JSON → 数据驱动生成 HTML（禁止硬编码数字）
7. 四重校验   → HTML 结构 / 图表对应 / JS 语法 / 视角禁词 / 隐私
8. 交付沉淀   → 口径声明 + 生成器留存（补数据改配置重跑）
```

## 数据口径三陷阱（本技能的核心资产）

真实赔案数据的三个系统性陷阱，不先诊断直接分析会得出错误结论：

| 陷阱 | 判定特征 | 处置 |
|---|---|---|
| **批次报销伪像** | 某月出险暴增（≥20%）/ 报案-出险间隔中位 >90 天 / 案均发票 >5 张 | 时间分析改用**报案日期口径** |
| **导出行数截断** | 年度件数恰为 2499/2500 等临界值 | 附录声明 + 提示分批重导 |
| **年度缺失/进行中** | 出险年度不连续；最近年度件数骤降 | 封面明示覆盖年度，不写"近N年" |

## 视角红线（报告质量的关键约束）

报告全程为 **HR / 员工健康 / 企业费用效率** 视角，校验器自动扫描禁词：

- 保险方内部语汇：核保、定价、赔付率、盈亏、费率、满期、超赔、承保、免赔额……
- 销售经营语汇：续保率、加保率、客户粘性、离不开、换不起……
- AI 味表述："一句话："式总结标签

## 安装与使用

```bash
# 安装：复制到用户级技能目录
git clone https://github.com/LC1023001/gi-chronic-risk-report.git
cp -r gi-chronic-risk-report/gi-chronic-risk-report ~/.workbuddy/skills/

# 分析器独立使用
python scripts/analyze_claims.py \
  --files "赔案明细1.xls" "赔案明细2.xls" \
  --stats "团体保单赔付统计报表.xlsx" \
  --unit "企业全称" --short "简称" --out _analytics.json

# 报告校验器独立使用
python scripts/validate_report.py 报告.html
```

依赖：`pip install xlrd`（xlsx 统计报表用标准库 zipfile 解析，无需 openpyxl）。

分析器输出摘要示例：

```

```

## 隐私与合规

- 个案呈现仅保留性别/年龄段/诊断/金额，脚本内置证件号、手机号泄漏扫描
- 报告附聚合视图声明：员工个人患病信息未经授权不向雇主披露
- 本仓库仅含方法论与工具，不含任何真实客户数据
